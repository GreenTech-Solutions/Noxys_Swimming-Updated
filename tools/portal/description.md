# Noxys Swimming (2.1)

> [Noxys Swimming](https://mods.factorio.com/mod/Noxys_Swimming) by Noxy, updated for Factorio 2.1 and published as `Noxys_Swimming-Updated`. All credit for the mod goes to Noxy. Source: [GreenTech-Solutions/Noxys_Swimming-Updated](https://github.com/GreenTech-Solutions/Noxys_Swimming-Updated).
>
> **Coming from Noxys Swimming?** Remove it: this mod replaces it and will not load next to it. Setting names are unchanged.

Now you can swim through water ... but beware ... so can **they**!

## Features
- Swimming!
- Amphibious vehicles
- Custom sounds
- Custom water animations
- Multiplayer compatible

## Companion mod

[Noxys Waterfill](https://mods.factorio.com/mods/CobaltSky/Noxys_Waterfill). With swimming, waterfill is not as cheaty or deadly as without it.
